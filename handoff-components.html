HPC-00문서 사용법 · 적용 범위

H.Point 앱 / Mobile Web / PC Web 3개 채널에서 반복 사용되는 공통 UI 컴포넌트의 단일 기준서입니다. 개별 화면설계서는 이 문서를 참조만 하고, 컴포넌트 규격을 다시 정의하지 않습니다.

이 문서가 정하는 것

  • Anatomy — 구성요소와 명칭 (모두가 같은 단어를 쓰게)
  • 규격·토큰 — 크기·간격·색·타이포의 확정 수치
  • 상태 정의 — default/hover/focus/active/disabled/loading/error/empty
  • 베리에이션 — 어떤 상황에 어떤 변형을 쓰는지의 판정 기준
  • 인터랙션 — 모션 duration/easing, 햅틱 토큰, 제스처
  • 접근성 — 마크업 규격, 키보드, 명암비, 터치타깃
  • 엣지케이스 — 개별 화면설계서에 반복해 적지 않기 위한 예외 목록
  • 운영 스펙 — CMS 등록 항목, 하드코딩/Admin 구분

이 문서가 정하지 않는 것

  • 화면별 콘텐츠·문구 (개별 화면설계서 소관)
  • 비즈니스 로직·API 스펙 (기능정의서 / 프로그램목록 소관)
  • 브랜드 최종 컬러·서체 (디자인 시스템 확정 시 0.1 토큰 블록만 교체)
  • 화면ID 채번 (프로그램목록 기준 — 아래 참조)
화면ID 기준 본 프로젝트 기준에 따라 화면ID는 프로그램목록을 기준으로 적용합니다. 공통 컴포넌트는 화면이 아니므로 화면ID를 채번하지 않고, 별도 컴포넌트ID(HPC-XX)를 부여해 화면설계서에서 참조합니다.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type":"ListItem", "position":1, "name":"고객센터",
      "item":"https://www.h-point.co.kr/cs" },
    { "@type":"ListItem", "position":2, "name":"자주 묻는 질문",

    { "@type":"ListItem", "position":3, "name":"포인트 적립" }
  ]
}
</script>
  • position은 1부터. 마지막 항목의 item은 생략(현재 페이지)
  • 진입 경로가 복수인 페이지는 하나의 스크립트에 BreadcrumbList 객체를 여러 개 선언

네이티브 → 웹뷰 주입 규격 개발 퍼블리셔

웹뷰 로드 시점에 네이티브가 아래 CSS 변수를 주입합니다. 퍼블리싱은 이 변수만 사용하고 수치를 하드코딩하지 않습니다.

/* 네이티브가 document.documentElement.style.setProperty 로 주입 */
--hp-header-h   : 0px | 52px    /* 네이티브 헤더 사용 시 0 */
--hp-bnb-h      : 0px | 60px    /* BNB 미노출 웹뷰는 0 */
--hp-inset-top  : 0px ~ 59px    /* 상태바 + 노치 */
--hp-inset-bottom: 0px ~ 34px   /* 홈 인디케이터 / 제스처 바 */
--hp-platform   : ios | android
--hp-app-version: 1.0.0

/* 퍼블리싱 사용 예 */
.page{
  padding-top:    calc(var(--hp-header-h,0px) + var(--hp-inset-top,0px));
  padding-bottom: calc(var(--hp-bnb-h,0px)   + var(--hp-inset-bottom,0px));
}
.sticky-cta{ bottom: calc(var(--hp-bnb-h,0px) + var(--hp-inset-bottom,0px)); }
fallback 필수 var(--hp-bnb-h, 0px) 처럼 반드시 기본값을 넣으십시오. 주입 실패 시 calc() 전체가 무효가 되어 레이아웃이 붕괴됩니다. 또한 웹뷰가 일반 브라우저에서도 열릴 수 있다는 전제로 작성해야 합니다(변수 미주입 = 웹 단독 모드).
